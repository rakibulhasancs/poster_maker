প্রচার পোস্টার মেকার
=====================

চালানোর নিয়ম:
  index.html ফাইলটিতে ডাবল-ক্লিক করুন (Chrome / Edge / Firefox / Safari)।
  ইন্টারনেট ছাড়াও কাজ করে।

ফোল্ডারের ফাইল:
  index.html   - পেজ
  style.css    - ডিজাইন
  script.js    - ছবি বসানো, নাম বসানো, ডাউনলোডের লজিক
  template.js  - পোস্টারের টেমপ্লেট (ফ্রেমের ভেতর ও নামের জায়গা ফাঁকা), পেজের ভেতর বসানো
  assets/fonts - বাংলা ফন্ট (Hind Siliguri)

অনলাইনে দিতে চাইলে পুরো poster-maker ফোল্ডারটি যেকোনো হোস্টিংয়ে (Netlify, GitHub Pages ইত্যাদি) আপলোড করুন।

পোস্টারের জায়গা পাল্টাতে চাইলে script.js এর ওপরের HOLE (ছবির জায়গা) ও NAME (নামের জায়গা) মান বদলান।
